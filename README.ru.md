Инструмент для локальной работы с JSON в одном HTML-файле с интерфейсом Graphite Studio. Просматривайте дерево и таблицы, редактируйте исходник, исследуйте точные значения и сравнивайте документы без установки, внешних библиотек и сервера.

Приложение написано на HTML, CSS и обычном JavaScript. Web Workers выполняют разбор, форматирование и сравнение. Python и Node.js не входят в приложение и не нужны для его запуска.

Тёмная палитра вдохновлена инструментами разработчика, включая IntelliJ IDEA. Это независимый проект.

## Быстрый запуск

1. Сохраните `JSON-Inspector-4.3-Graphite.html` на компьютер.
2. Откройте его в современном браузере.
3. Нажмите «Открыть», перетащите JSON-файл в окно или вставьте текст во вкладке «Исходник JSON» и нажмите «Применить».
4. Нажмите «Пример», чтобы посмотреть встроенный документ.
5. Для сравнения примените основной документ, откройте JSON Diff и загрузите второй файл.

Сборка, менеджер пакетов и локальный веб-сервер не нужны. Приложение работает с локальной страницы `file://` с учётом настроек безопасности браузера.

Для фоновых задач нужен Web Worker из Blob URL. Если браузер блокирует запуск Worker, приложение показывает ошибку; скрытого перехода к синхронному разбору нет.

- Более светлые графитовые панели, крупнее текст и кнопки, мягче скругления и свободнее отступы.
- Стартовый экран по центру с открытием файла, примером и переходом в редактор.

- Встроенный справа инспектор, который не перекрывает документ на большом экране.
- Изменение ширины инспектора мышью и клавиатурой; нижняя панель на узких экранах.
- Просторная плотность по умолчанию и переключатель «Компактнее / Просторнее».
- Отдельная отметка состояния документа рядом с подробным описанием.
- Статистика под рабочей областью.
- Встроенные SVG-иконки без библиотек и внешних ресурсов.
- Отключение переходов интерфейса при включённой настройке уменьшенного движения в браузере.

Сохранены фоновая обработка, отмена задач, защита черновика, Diff, отчёты, переход к ошибкам и переключение английского и русского языков.

## Работа с документами

### Черновик, применённый документ и экспорт

Это отдельные состояния:

- В редакторе находится текущий черновик.
- «Применить» разбирает черновик и обновляет дерево, таблицы, инспектор и статистику.
- «Форматировать» и «Минифицировать» меняют черновик, но не применяют его автоматически.
- «Копировать» копирует текущий текст исходника, включая неприменённый или некорректный черновик.
- «Скачать» сначала применяет и проверяет текущий исходник, затем запрашивает скачивание JSON.

Переключение вкладок или языка не заменяет черновик применённым документом.

При ошибке разбора последний применённый документ остаётся доступным. Строка состояния показывает, когда представления отличаются от черновика. Предупреждения перед заменой файла и закрытием страницы помогают избежать потерь с учётом ограничений диалогов браузера.

Запрос скачивания не доказывает, что браузер сохранил файл. Проверьте результат. Входной файл не редактируется на месте.

### Дерево, таблицы и инспектор

Нажмите значение в дереве, чтобы открыть инспектор. Кнопка ↗ открывает в таблице контейнер или родителя значения. В таблицах нажимайте значения для просмотра узлов и ↗ рядом с контейнером для перехода внутрь.

«Записи» объединяют свойства объектов в колонки. Отсутствующие свойства обозначаются `—`; JSON null остаётся значением. «Пути» показывают конечные значения и пустые контейнеры под выбранным корнем таблицы.

Инспектор поддерживает переход к родителю, копирование пути и поддерева и закрепление. На большом экране он встроен справа: меняйте ширину перетаскиванием разделителя или с клавиатуры, переведя на него фокус. На узком экране инспектор открывается нижней панелью и может перекрывать нижнюю часть рабочей области; закройте его, чтобы снова видеть документ без перекрытия. Длинный предпросмотр обрезается; копируется полный исходный фрагмент. Кнопки цепочки родителей переходят к соответствующим узлам. Закрепление сохраняет инспектор открытым при применении документа; кнопка закрытия и Esc по-прежнему его закрывают.

Внутренние связи используют числовые индексы, а не отображаемые пути.

## Поиск и пути

Включите «Ключи», «Значения», «Пути» или их комбинацию. Области объединяются по ИЛИ; дополнительный фильтр ограничивает результат одним типом узла.

«Точное совпадение» сравнивает отдельное поле поиска целиком. «Учитывать регистр» сохраняет различие регистра. Поиск буквальный, без регулярных выражений; регистронезависимый режим не реализует полное Unicode case folding.

Строки ищутся в декодированном виде, числа — по исходному токену, логические значения и null — по JSON-записи. Для объектов и массивов поиск по значению использует название типа, а не сериализованное содержимое.

Кнопки ↑ / ↓ рядом с полем перемещают между совпадениями. Раскройте «Параметры поиска», чтобы изменить области и правила совпадения. Нажатие на метку активного фильтра со знаком × отключает соответствующую настройку. «Сбросить поиск» очищает запрос и параметры. Поиск выполняется в основном потоке с небольшой задержкой после ввода.

Поддерживаемые пути:

```text
$
$.users[0].name
$["users"][0]["name"]
$["key.with.dot"]["hello world"]
```

В канонических путях ключи объектов записаны в JSON-кавычках. Для пунктуации, пробелов, Unicode и необычных имён используйте скобочную запись. Это не полноценный JSONPath: шаблоны, фильтры, рекурсивный спуск, срезы и исполняемые выражения не поддерживаются.

## JSON Diff

Сравниваются последний применённый основной документ и отдельно загруженный второй документ. Сначала примените правки исходника, если хотите включить их в сравнение.

| Статус | Значение |
| --- | --- |
| Добавлено | Только во втором документе |
| Удалено | Только в основном документе |
| Изменено | Отличается тип, значение или содержимое потомков |
| Без изменений | Равенство по выбранным правилам |

При изменении потомков родитель получает статус «Изменено». Интерфейс отдельно указывает изменения внутри контейнера. Счётчики считают узлы, включая контейнеры, а не независимые операции редактирования.

### Правила сравнения

- Свойства объектов сопоставляются по декодированным ключам; порядок не учитывается.
- Массивы сопоставляются по индексам, без распознавания перемещений и сдвигов.
- Строки сравниваются по декодированному значению, а не записи escape-последовательностей.
- Пробелы форматирования не влияют на семантическое равенство.
- Повторяющиеся декодированные ключи отклоняются в обоих документах.

Режим точного числового значения нормализует десятичный коэффициент и экспоненту BigInt без преобразования в JavaScript Number. Эквивалентные десятичная и экспоненциальная записи равны. Отдельный переключатель различает отрицательный и положительный ноль.

Режим исходной записи числа сравнивает точное написание, включая форму записи и завершающие нули; запись отрицательного нуля в этом режиме всегда отличается.

### Работа с Diff

- Загрузите второй файл. «Поменять стороны» меняет документы местами и заменяет содержимое основного редактора с предупреждением при необходимости.
- Обновите сравнение после применения основного документа или изменения режима сравнения чисел. Устаревшие результаты не выдаются за актуальные.
- Используйте «Только различия», фильтр статуса, поиск и страницы.
- Переходите к предыдущему и следующему изменению.
- Нажмите путь, чтобы раскрыть фрагменты обеих сторон и список потомков. Длина показанных фрагментов и списка потомков ограничена.
- Нажмите значение для копирования полного фрагмента; ↗ переводит к узлу основного документа в дереве.

### Экспорт отчёта

«Экспорт отчёта» скачивает JSON с именами файлов, настройками, счётчиками, статусами узлов, исходными текстами документов и диапазонами узлов. Диапазоны используют смещения UTF-16 с нуля; конечная граница не включается.

Каждый исходный документ включается один раз, а строки отчёта ссылаются на диапазоны вместо повторения поддеревьев. Отчёт содержит полные исходные документы: если входные данные конфиденциальны, отчёт тоже конфиденциален.

Экспорт включает все строки сравнения, а не только текущую страницу или фильтр. Он описывает применённые документы, а не неприменённый черновик. Входные файлы не изменяются.

## Целостность данных

### Точные числовые токены

Форматирование, минификация и копирование сохраняют такие значения:

```json
{
  "largeId": 9007199254740993,
  "precise": 0.123456789012345678901,
  "negativeZero": -0,
  "largeExponent": 1e999
}
```

Числа хранятся как текст. При точном сравнении большие экспоненты не разворачиваются в десятичные строки. Другие инструменты всё равно могут не поддерживать точное представление этих значений.

### Некорректный ввод и Unicode

Повторяющиеся декодированные ключи отклоняются, а не перезаписываются: `"a"` и `"\u0061"` считаются одинаковым ключом. Это намеренная политика приложения.

Ожидается JSON, а не JSON5 или JSON Lines. Комментарии, завершающие запятые, NaN, Infinity, некорректные escape-последовательности и неэкранированные управляющие символы отклоняются.

Одиночные UTF-16-суррогаты вызывают предупреждения без исправления или нормализации исходника. Запись предупреждения указывает начало строкового токена и смещение внутри декодированной строки, а не точную позицию каждого суррогата в исходной записи. Список показывает до 100 предупреждений.

Файлы декодируются как UTF-8; некорректные байтовые последовательности отдельно не проверяются. Начальный BOM удаляется при открытии обоих файлов.

Диагностика показывает фрагмент строки и предлагает переход в редактор, если ошибка относится к его текущему тексту.

## Фоновая работа и производительность

Разбор, форматирование и сравнение используют отдельные Worker-сервисы. Новая задача отменяет предыдущую в том же сервисе; отмена форматирования не отменяет сравнение автоматически.

Worker-сервисы переиспользуются. Сравнение кеширует активные входные документы; перезапуск сервиса очищает кеш. Перед использованием результат проверяется по версии документа.

Поиск, подсветка, списки контейнеров, передача модели, подготовка отчёта и отрисовка DOM всё ещё требуют работы в основном потоке. Полностью неблокирующий интерфейс не гарантируется.

Параметры поиска можно свернуть; кнопка «Статистика» показывает или скрывает полосу под рабочей областью. Режим «Только данные» скрывает второстепенные панели; «Вернуть панели» восстанавливает их.

Минимальная ширина компоновки — 360 px. Адаптивные стили не означают полной проверки мобильного удобства. Используются современные возможности CSS, включая `:has()` и динамические единицы высоты окна.

Доступ к буферу обмена зависит от браузера. Если копирование не сработало, выделите исходник и используйте обычное сочетание клавиш.

## Приватность и безопасность

- Локальная обработка, без сетевых запросов приложения и зависимостей времени выполнения.
- Документы не сохраняются в localStorage, IndexedDB или cookies.
- Пользовательские данные вставляются текстовыми DOM-операциями, а не интерполяцией HTML.
- Поиск свойств использует Map; пути не исполняются как код.
- CSP блокирует сетевые соединения, встроенные объекты и фреймы; встроенные скрипты, стили и Blob Worker разрешены.
- Копирование, скачивание JSON и экспорт отчёта инициирует пользователь.

Локальная обработка не защищает от скомпрометированного браузера, расширений, операционной системы или изменённой копии HTML. Обращайтесь с отчётами и буфером обмена согласно своим требованиям.

Значки Shields.io относятся только к документации; HTML их не загружает.

## Язык

Нажмите EN или RU для переключения на указанный язык. Начальная настройка следует языку браузера: русский для русскоязычной настройки, иначе английский. JSON и имена файлов не меняются. Настройка не сохраняется между сеансами.

## Проверки

При подготовке сборки 4.3 Graphite Studio зафиксированы:

- 122 проверки вычислительного ядра на функциях, извлечённых из сгенерированного HTML.
- Подтверждение неизменности блока вычислительного ядра относительно переданной сборки 4.2.
- Проверка синтаксиса JavaScript, отсутствующих и повторяющихся DOM-идентификаторов.
- Сценарии в headless Chromium: стартовый экран, сохранность черновика, форматирование, переключение языка, отключение фильтров, встроенный инспектор, изменение ширины с клавиатуры, плотность, навигация по дереву, Diff, скачивание отчёта, смена сторон, переход к ошибке и режим «Только данные».
- Проверка компоновки на нескольких размерах окна и отдельная проверка нижней панели инспектора с корректным применённым документом.

Прежние 161 проверка ядра и 30 браузерных проверок относятся к сборке 4.2, а не являются результатами 4.3.

Для использования приложения не нужны команда Node.js или отдельный тестовый файл. Это зафиксированные результаты разработки, а не гарантия корректности изменённых копий.

Полная межбраузерная проверка и сертификация доступности не выполнялись. Другие браузеры, экранные дикторы, системный буфер обмена, перетаскивание и визуальное удобство требуют дополнительной ручной проверки. Работа на узких экранах, особенно с одновременно открытыми диагностикой и инспектором, нуждается в дальнейшей оценке удобства.
