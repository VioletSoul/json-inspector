Компактный локальный JSON-инспектор в одном HTML-файле. Дерево, таблицы, инспекция значений и редактор исходника — без сервера, установки и внешних библиотек.

Интерфейс отдаёт основную часть окна данным, а не декоративным блокам. Тёмная палитра вдохновлена инструментами разработчика, включая IntelliJ IDEA; это независимый проект.

## Быстрый старт

1. Сохраните `json-inspector-3.0.html` на компьютер.
2. Откройте файл в современном браузере.
3. Нажмите **Открыть**, перетащите JSON-файл в окно или вставьте текст во вкладку **Исходник JSON** и нажмите **Применить**.
4. Для знакомства с возможностями нажмите **Пример**.

Сборка, менеджер пакетов, Python и локальный веб-сервер не нужны. Приложение работает при открытии локальной страницы через `file://`.

### Русский / английский интерфейс

Кнопка **EN** переключает интерфейс на английский, **RU** — на русский. На кнопке указан язык, на который можно перейти.

Переключаются элементы управления, подсказки, доступные названия элементов, заголовки таблиц, описания типов, ошибки, статусы, подтверждения и инспектор значения. Сам JSON, его ключи, значения и имена файлов не переводятся и не изменяются.

Начальный язык определяется языком браузера: русский при русской настройке, иначе английский. Выбор действует только в текущем сеансе страницы. Ни языковая настройка, ни JSON не записываются в хранилище браузера.

### Работа с деревом и таблицами

- Нажмите значение в дереве, чтобы открыть инспектор. Кнопка **↗** открывает контейнер или родителя простого значения в таблице.
- Нажмите значение в таблице для инспекции именно этого узла; **↗** рядом с контейнером открывает его содержимое.
- Режим **Записи** объединяет свойства объектов массива в колонки. Отсутствующее свойство обозначается `—`, а JSON `null` остаётся отдельным значением.
- Режим **Пути** показывает конечные значения и пустые контейнеры выбранной ветки.
- Поиск временно показывает совпадения вместе с предками. После очистки восстанавливается прежнее раскрытие дерева.
- Для длинного значения показывается фрагмент рядом с совпадением. Через инспектор можно скопировать полное исходное значение.

### Пути

Примеры поддерживаемой записи:

```text
$
$.users[0].name
$["users"][0]["name"]
$["key.with.dot"]["hello world"]
```

Канонические пути используют ключи объектов в двойных JSON-кавычках. Запись через точку принимает имена, похожие на идентификаторы. Для пробелов, пунктуации, Unicode-ключей и необычных имён используйте скобки с двойными кавычками.

Это не полноценный движок JSONPath: wildcard, фильтры, рекурсивный спуск, срезы и исполняемые выражения не поддерживаются.

## Сохранность данных

### Точная запись чисел

Парсер хранит числовые токены текстом, не преобразуя их в JavaScript `Number`. Форматирование и минификация сохраняют, например:

```json
{
  "largeId": 9007199254740993,
  "precise": 0.123456789012345678901,
  "negativeZero": -0,
  "largeExponent": 1e999
}
```

Значения отображаются и экспортируются без числового вычисления. Приложение не выполняет арифметику и не гарантирует, что сторонние инструменты смогут представить те же числа.

### Дубликаты ключей и ошибки ввода

Повторяющиеся декодированные ключи отклоняются, а не перезаписываются молча. Например, `"a"` и `"\u0061"` считаются одним ключом. Диагностика содержит строку и столбец.

Ожидается JSON, а не JSON5 или JSON Lines. Комментарии, запятые после последнего элемента, `NaN` и `Infinity` отклоняются. При открытии файла удаляется начальный BOM. Файл декодируется как UTF-8; отдельной проверки некорректных байтовых последовательностей нет.

При ошибке разбора дерево, таблица и статистика сохраняют последнюю применённую версию. Исправьте исходник и примените его заново.

### Применение — не сохранение

Кнопка **Применить** обновляет представления, но не сохраняет файл. Изменённый текст остаётся неэкспортированным до запроса **Скачать**. Подтверждения замены и закрытия страницы помогают избежать потери изменений с учётом ограничений браузерных диалогов.

Страница может запросить скачивание, но не может подтвердить, что браузер его завершил. Проверьте фактическое сохранение файла. Исходный входной файл не редактируется на месте.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `⌘ + Enter` / `Ctrl + Enter` в редакторе | Применить JSON |
| `Tab` в редакторе | Вставить два пробела |
| `Enter` в поле пути | Перейти к узлу |
| `Esc` | Закрыть инспектор |
| `←` / `→`, когда вкладка в фокусе | Переключить вкладку |
| `Home` / `End`, когда вкладка в фокусе | Первая / последняя вкладка |

Доступ к буферу обмена зависит от разрешений браузера. Если автоматическое копирование недоступно, выделите исходник и используйте обычное сочетание клавиш копирования.

## Ограничения

| Ресурс | Лимит |
| --- | ---: |
| Входной / отформатированный документ | 5 МиБ |
| Узлы | 20 000 |
| Глубина вложенности | 100; глубина корня — 0 |
| Суммарная длина канонических путей | 4 194 304 кодовые единицы UTF-16 |
| Страница дерева | 250 узлов |
| Страница таблицы | 100 строк |
| Колонки свойств в режиме «Записи» | 40 плюс колонка индекса |
| Исходник с подсветкой | 200 000 кодовых единиц UTF-16 |
| Предпросмотр инспектора | 100 000 кодовых единиц UTF-16; копируется полное значение |

При превышении лимита колонок выводится предупреждение. Пропущенные значения доступны в режиме «Пути». Для большого текста подсветка и номера строк отключаются, редактор остаётся доступен.

Разбор выполняется в главном потоке. Консервативные лимиты снижают нагрузку, но не гарантируют мгновенный отклик на любом устройстве. Поиск — нечувствительное к регистру сопоставление подстрок, без регулярных выражений и полного Unicode case folding.

## Приватность и безопасность

- JSON обрабатывается локально в браузере.
- Приложение не делает сетевых запросов и не имеет внешних зависимостей времени выполнения.
- JSON не сохраняется в `localStorage`, IndexedDB или cookies.
- Пользовательские значения вставляются текстовыми DOM-операциями, а не HTML-подстановкой.
- Для поиска ключей используется `Map`; пути не исполняются как код.
- Content Security Policy запрещает сетевые подключения, встроенные объекты и фреймы. Inline-скрипты и стили разрешены для автономного однофайлового приложения.
- Копирование и экспорт запускаются пользователем.

Локальная обработка не защищает от скомпрометированного браузера, расширений, операционной системы или изменённой копии HTML. Учитывайте собственные требования к экспортированным данным и содержимому буфера обмена.

## Проверки и совместимость

Для этой редакции выполнены проверка синтаксиса JavaScript, проверки идентификаторов и целостности script-элемента HTML, 693 проверки парсера/форматирования/путей и 383 проверки состояния интерфейса/переводов на минимальном DOM-макете. Включены 300 сгенерированных JSON-документов, точность числовых токенов, некорректный ввод, дубликаты ключей, пути, лимиты и переключение языка без изменения исходника.

DOM-макет не заменяет браузер. Визуальная компоновка, скринридер, скачивание, перетаскивание и системный буфер обмена требуют ручной проверки в браузере. Кросс-браузерная сертификация и гарантия полной безопасности не заявляются.
